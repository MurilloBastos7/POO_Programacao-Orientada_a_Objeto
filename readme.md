# 💻 Programação Orientada a Objetos (POO)

Repositório dedicado aos estudos, exercícios e conceitos práticos da disciplina de **Programação Orientada a Objetos** em PHP.

---

## 📌 Conteúdo do Repositório

Neste repositório você encontrará exemplos práticos e atividades focados nos pilares da POO:

- **Classes e Objetos**: Estruturação de dados e comportamentos.
- **Encapsulamento**: Uso de visibilidades (`public`, `protected`, `private`).
- **Herança**: Reutilização de código e extensão de classes.
- **Polimorfismo & Sobrescrita**: Sobrescrita de métodos para diferentes comportamentos.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem**: PHP
- **Diagramas**: Mermaid / PlantUML
